# Calculadora Geometrica Basica

## Descripcion
Un programa simple en Python para realizar calculos de geometria elemental.

## Lenguaje
Python 3

## Funciones
- calcular_area_rectangulo: Recibe la base y altura y retorna el area del rectangulo.
- calcular_perimetro_rectangulo: Recibe la base y altura y retorna el perimetro.

## Como ejecutar
python calculadora.py
